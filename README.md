# mikrotik-routing-lists-output

Автоматически публикуемые IPv4 address-list для MikroTik RouterOS 7.

- `ru-direct.rsc` — команды добавления списка `ru_direct`;
- `ru-direct.txt` — тот же список в обычном CIDR-формате;
- `ru-all.*` — исходный российский GeoIP до исключений;
- `manifest.json` — количество записей и SHA-256;
- `stats.json` — подробная статистика сборки.

Файлы генерируются закрытым проектом [mikrotik-routing-lists](https://github.com/AbdulBashirov/mikrotik-routing-lists). Репозиторий не содержит конфигурацию MikroTik, ключи или секреты.
